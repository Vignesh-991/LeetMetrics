# LeetMetrics

A web-based LeetCode statistics dashboard built using HTML, CSS, and JavaScript.

## Features

- Search LeetCode users by username
- Display total problems solved
- Show Easy, Medium, and Hard problem progress
- Display acceptance rate
- Display LeetCode ranking
- Display contribution points
- Analyze top solved problem topics
- Responsive dashboard interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- REST API
- Fetch API
- DOM Manipulation

## API

LeetMetrics retrieves user statistics from the LeetCode Stats API.

## How to Run

1. Clone the repository.
2. Open `index.html` in a browser.
3. Enter a valid LeetCode username.
4. Click **Search**.
